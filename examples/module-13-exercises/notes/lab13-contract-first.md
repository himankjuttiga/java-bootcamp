# Lab 13 — Contract-First Mindset

## Step 1 — Definition


Contract-first means defining the service's types and operations in an XSD schema and a
WSDL contract before writing or generating any Java, so the XML contract is the source of
truth and the Java classes are generated from it, not the other way around.
